Edit video on your phone.
Fully offline.

Vynox is a real multi-layer editor for Android: cut, trim and split on a timeline, animate anything with keyframes and a Bezier graph editor, add text, shapes, masks, GPU effects and blend modes — then export a genuine MP4 (not a screen recording). No account, no upload, no internet required.

Offline by design

Import, edit, preview and export with no network. The only optional call is the update check on the home screen.

Your projects, portable

Projects save as versioned .vnx files, optionally bundling their media, so one file is the whole edit.

Real rendering

OpenGL ES compositing with 10 blend modes, per-layer masks, colour grading, blur, sharpen and glow.

What you can do

Timeline

Multi-layer clips, split at playhead, in/out trim, drag with snapping, markers, zoom and scrub.

Keyframes

Linear, hold and Bezier easing on position, scale, rotation, opacity and every effect parameter.

Graph editor

Shape interpolation curves by hand. Editing the graph changes how the animation actually plays.

Text

Editable text layers with size, weight, spacing, alignment, stroke, shadow and background.

Shapes

Rect, rounded rect, ellipse, line and polygon with fill, stroke and corner control.

Masks

Rectangle, ellipse and path masks with position, size, rotation, feather, opacity and invert.

Effects

Blur, brightness, contrast, saturation, hue, exposure, sharpen, glow, vignette, tint, invert, temperature.

Blending

Normal, multiply, screen, overlay, add, darken and more, composited per layer on the GPU.

Audio

Import audio and video sound, per-layer volume and mute, resampled preview playback, AAC in export.

Export

MP4 (H.264 + AAC) with resolution, frame rate and bitrate control, progress and cancellation.

Reliability

Undo/redo, local autosave with recovery, and a relink screen when media goes missing.

Format

Versioned .vnx schema, decoupled from the UI, with shared/bundled project support.

Install

  1. Tap Download APK to get the latest signed release.
  2. Open the downloaded file. Android will ask for permission to install from this source — allow it for your browser or files app.
  3. Tap Install, then open Vynox and grant media permission when you import your first clip.

Requires Android 8.0 (API 26) or newer. Releases are signed; if Android warns about an unknown source, that is the normal side-loading prompt, not a problem with the file.
